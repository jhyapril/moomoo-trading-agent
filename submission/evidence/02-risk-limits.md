## 发单前的检查顺序（`rules/risk.md`）

12 项，全部通过才可下单，**检查发生在订单发出之前而不是成交之后**：
账户 → 模拟盘 → 仓位 → 加仓（确认腿单独再过一遍全表） → 敞口 → 杠杆 → 现金缓冲 →
持仓数量 → 当日亏损 → 回撤 → 交易频次 → 标的范围。

## 升级阶梯（触发即执行，不讨价还价）

| 触发 | 动作 |
|---|---|
| 触及当日亏损上限 | 停止开仓、平仓、报告，等下一交易日 |
| 触及回撤上限 | 平仓、停用策略、报告；**恢复由人决定，agent 不得自主重启** |
| 鉴权 / 权限失败 | 停止交易，报告确切错误码，**绝不循环重试** |
| 数据过期或缺失 | 跳过该标的并记入 journal，**不得用过期价格替代** |
| 模型 / agent 不确定 | 默认不交易，记录原因 |
| 一个会话内三次违规 | 停止运行 |
