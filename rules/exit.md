# 出场流程

每次运行对所有持仓逐一评估出场条件，且排在入场逻辑之前。出场永不因风控容量被阻塞。

## 优先级

1. **硬止损** — 相对平均成本的 `per_trade_stop_pct`，或更紧的策略止损。券商侧支持止损
   就用券商侧；否则每次运行用可成交限价检查。
2. **逻辑失效** — 持仓理由不再成立。下一次评估即出场，无论盈亏。
3. **目标** — 达到既定目标即止盈。
4. **时间止损** — 持有超过 `STRATEGY.md` §5 的期限。
5. **清仓** — 若设置了 `cadence.flatten_by` 且已过时点，清空全部持仓。
6. **熔断** — 回撤或当日亏损触限：平仓、停用开仓、报告。

## 部分出场

仅当 `STRATEGY.md` §5 预先定义时才允许。否则出场必须全有或全无；临时部分出场属于违规。

## 每次出场之后

- 记录：成交价、相对意图的滑点、已实现盈亏、触发规则。
- 若为止损出场，再次入场同一标的必须遵守 `cooldown_after_stop_minutes`。

## 禁止

- 把止损往远离持仓的方向移动。
- 止损后同一会话内、冷却期未过就重回同一标的。
- 设置了 `flatten_by` 却持仓过夜。
