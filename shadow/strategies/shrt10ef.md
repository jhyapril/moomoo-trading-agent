# shrt10ef：shrt10 逐字复制，唯一改的是财报门"数未来日期"

- 目的：现行 `signal.earnings_blackout_days`（config 注释原话"财报**前** N 天内不开新仓"）与
  `rules/entry.md` Gate 3 / STRATEGY §4.1 第 4 条写的"财报在 3 天内不进"不是同一件事。前者只该拦**尚未发生**的
  发布，后者按字面会把**刚发布完**的标的也关三天。2026-11-23 上午做空族唯一的合格信号正好落在这句话上
  （CRWD），所以我用一本真实账本来量这句话值多少钱，而不是继续口头并存两种读法。
- 本小时的实测依据（只读，可复算）：`quote_financials_earnings_price_history US.CRWD` 返回
  `data.records` **586 条**，其中 **0 条 `pub_trading_day_str` 晚于 2026-11-23**；`is_current=true` 的那组
  （16 条 offset 记录）`pub_time_str = 2026-11-23 09:00:00`、`pub_trading_day_str = 2026-11-23`、
  `period_text = 2027/Q3`、`schedule_delta` 范围 −15…+14。也就是说**这个数据源根本没有"下一次财报日"字段**，
  它给的是"最近一次已发布 + 该日前后 ±15 个交易日的表现"。因此任何按此源实现的财报门，实际只能是
  **回溯的**：标的刚发完财报（事件风险已释放）会被拦 3 天，而它真正该被拦的那一天（发布前）反而查不到日期。
- 标的：现行策略的 14 只标的（同 shrt10）。
- 入场（与 `shrt10` 逐字相同，只把最后一条财报门替换）：
  - 实时价低于近 10 个已收盘交易日的最低价 lo10（截至上一收盘，盘中不重算），且满足任一条：
    - 价格 ≤ lo10 ×0.98；
    - 连续 120 根 1 分钟收盘不回到 lo10 之上。
  - 实时价 < MA50（含实时价口径）。
  - 不要求 MA20<MA50，不要求跌破 20 日低，**没有 RSI/%B 过热门**（该门由 shrt10f 承载）。
  - 时窗：保留 `cadence.entry_window` 09:30–15:30（同 shrt10）。
  - **财报门（本账本唯一的变量）**：只有当数据源里存在**晚于判定日**且距判定日 ≤ 3 个交易日的计划发布日时，
    才不进。最近一次已发布的日期（含"今日盘前已发布"）**不拦**——发布已发生，事件风险已释放。
    源里没有未来日期时，本条按"无即将到来的财报"处理 = **放行**（这一处理与 shrt10 文本的"日期未知时放行"
    同向，但与现行策略的 fail-closed 相反，见下"已知缺陷"③）。
- 成交约定：做空开仓按**买一价**（我作为卖方吃 bid，NASDAQ/ARCA 取较低买一）；回补按卖一价（取较低卖一）。
  `filled_at` 取该盘口自己的 `exchange_data_time_ms`；判定与成交用同一个数、不回填。
- 仓位：镜像现行 §6——1% 权益 ÷ 每股止损距离（= min(5%×价, 2×ATR14)），单只上限 20%，一次建满不分两段。
  最多同时做空 4 只；多只同时合格而席位不够时，按跌破 lo10 的深度从大到小取（同 shrt10 2026-11-20 补定）。
- 出场（与 shrt10 逐字相同）：止损 = 均价 + min(5%×均价, 2×ATR14)；止盈 = 均价 ×0.90；10 个交易日时间止损；
  逻辑失效 = **收盘**高于当日固定的 50 日收盘 MA50 时回补。
- 与 `shrt10` 的对照关系：两本同日、同门、同价、同仓位，唯一分歧来自财报门读法 →
  `shrt10ef − shrt10` 就是这句话在一个具体标的上的代价（可能为正也可能为负，样本少时照直说）。
- 已知缺陷（写在这里，事后不换尺子）：
  1. **规则与本笔成交同一时刻定义**，首笔没有独立样本（同 pbd50/shrt10/brk10i 自陈的同类缺陷），
     真正的前瞻样本从第二次分歧开始。
  2. 因为该源永不给出未来日期，本账本这道门**此刻实际恒不触发** → 本本等价于"shrt10 完全去掉财报门"。
     所以两本的差值不只包含"读取口径"这一格，还包含"事件后追跌的整段敞口"。这条限定必须跟着读数一起报，
     否则会把一段方向性暴露读成一条规则的价格。
  3. 现行策略对此门的另一处依赖我**不复现也不引用**：11/20 收盘任务预写的"CRWD 12-01 实时复核 true"
     不是出自本工具（本工具 0 条未来记录），其来源不在影子侧可核 → 按 11/23 待办 ⑪，本影子每轮只用当日实时读数。
  4. 本账本不建模融券成本与借券可得性（与 shrt10 族同源缺陷）；费用按 `config.cost`，开空计 SEC+TAF。
- 与既有留档的关系：2026-11-23 待办 ⑪「期间做空族对 CRWD 一律 0 笔」约束的是**已开的那 6 本按各自文本执行**
  （它们的文本写"已知日期且在 3 天内不进"，故 0 笔、本轮不改写）。本账本是新增的对照本，不并入那 6 本的读数。
