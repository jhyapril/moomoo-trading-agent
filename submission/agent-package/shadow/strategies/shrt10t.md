# shrt10t：同一入场信号下，把出场从"固定止损+固定止盈"换成"等距移动止损"

- 本本要检验的量不是"赚多少"，而是**有利偏移的捕获率** = （实现盈亏 + 在场浮盈）÷ 建仓后可观察到的最大有利偏移。
  它把"方向判对但没拿到"这件事变成可读数字，而现行 §5 和现有 21 个账本都没有任何一条线在读这个数。
- 假设（事前登记，2026-11-24 19:46:14 ET）：做空侧的 +10% 固定止盈离入场价太远、固定止损又常压在当日极值附近，
  于是"跌下去又收回来"的一天会全额回吐。若成立，移动止损应在同样的入场信号下拿到明显更高的捕获率；
  若不成立（捕获率不升反降，或被更频繁地在反弹里打掉），则支持保留现行的固定止盈+固定止损对。
- **动机是后验的**：这个想法来自 2026-11-24 AMD 一个交易日的读数（做空腿在 11:18 低点曾有利 +3,910.10 美元，
  收盘反而不利 −1,556.47，回吐 5,466.57，而止盈线 367.524 距日低还差 +7.755% 一直没碰到）。
  n = 1 天，所以本本**不得回填那笔成交**，第一笔只能是 11/25 09:30 ET 之后的新信号；在此之前它没有样本、只有规则。
- 入场：与 `shrt10` 逐字相同（§4.2 做空分支的复制：较低买一 < 固定 lo10 且 ≤ lo10×0.98 的价格分支，
  或连续 120 分钟不收回 lo10 的时间分支；价 < MA50 含实时；财报按本系既有口径；09:30–15:30 窗内；席位上限 4）。
  **刻意不动任何入场变量**，这样 shrt10 与 shrt10t 的差值只可能是出场方式造成的。
- 仓位：与 shrt10 同一把尺 —— 股数 = 1% 权益 ÷ 每股止损距离 min(5%×价, 2×ATR14)，单只上限 20%。
  移动止损用的是**同一个距离数值**（入场时锁定，不随 ATR 更新），所以两本在同一信号上的股数应当一字不差；
  若出现股数差异，先查是不是入场时刻的权益读数不同，不要归因给出场。
- 出场（唯一差异区）：
  - 移动止损：线 = 建仓后已观察到的最高不利价 − 锁定距离；对空头即"线 = 最低价 − min(5%, 2×ATR14)"上移，
    只朝有利方向移动、永不回撤。用买一价（空头回补的可成交价）判定与成交，同一个数。
  - **取消** +10% 固定止盈。
  - **取消** 入场日写死的固定止损线（它被移动止损的第一档取代，第一档就等于原线）。
  - 保留 MA50 收盘确认的逻辑失效线、保留 10 个交易日时间止损。
- 读数纪律（从 11/24 的教训直接搬过来，本本第一笔起就生效）：
  - 移动止损的"已观察极值"**从该笔的真实观测时刻起算**，不从 `filled_at` 起算。
    `shadow.py` 的 `filled_at` 同时承担入场时点、极值窗口起点、`late_fills` 判定三件事，11/24 已实测它会因一次
    小时级笔误产生两套自相矛盾的合法读数（AMD 七本：按 `filled_at` 该全部止损、按真实观测时刻 0 触发，差 4,916.04 美元）。
  - 极值窗口只用**该腿自己建仓之后**的分钟线，不串用同日更早批次的读数。
  - 建仓时刻的 ATR14 / lo10 / MA50 一律从日线缓存 + 官方分钟线原样复制，不凭记忆填参数。
- 与现行策略的关系：现行 §5 是"止损 min(5%, 2×ATR) / 止盈 +10% / 10 日时间止损 / 收盘跌破 MA50"。
  本本只动止盈与止损的形态，不动风险预算，因此它对现行 §5 的建议将限定在"出场段"，且必须先有 ≥ 数笔样本。
